# Фильтрация данных в Excel на Python (pandas)

Простой скрипт для автоматической обработки Excel-файлов. Читает исходные данные, фильтрует строки по заданному условию и сохраняет результат в новый файл.

## 🛠️ Что умеет:
1. Читает файл `data.xlsx`.
2. Фильтрует данные (в данном примере — оставляет людей старше 24 лет).
3. Сохраняет результат в новый файл `result.xlsx` без лишних индексов.

## 🚀 Как запустить:
1. Установите библиотеки: `pip install pandas openpyxl`
2. Запустите: `python main.py`

## 📊 Результат:
В папке появится файл `result.xlsx` с отфильтрованными данными.
